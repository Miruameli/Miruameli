## About

I'm Miruameli — a software developer who likes building small systems end to
end, from the first line of code to the command that runs it. I write mostly in
**Rust** and **Python**: Rust when speed and ownership of the details matter,
Python when the shape of the idea is still moving.

I'm not chasing the largest system. I'd rather ship something small that other
people can rerun, measure, and disagree with.

## How I work

| Principle | What it means in practice |
| --- | --- |
| Measure first | A claim without a number is just a claim |
| Small before big | The smallest thing that answers the actual question |
| Write down failures | Bugs and dead ends get recorded, not quietly patched |
| Reproducible or useless | Pinned dependencies, seeded runs, tests that fail loudly |

## Stack

| Area | Tools |
| --- | --- |
| Systems, performance, CLIs | Rust (cargo, clap, tracing) |
